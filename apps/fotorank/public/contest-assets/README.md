# Contest assets (públicos, manuales)

Ubicación canónica para assets visuales de concursos públicos en FotoRank.

```
public/contest-assets/{slug}/
  hero/
  identity/
  identity/logos-secondary/
  editorial/
  gallery/
  social/
```

- Solo JPEG, PNG o WebP.
- No SVG hasta auditar el pipeline.
- No placeholders ni stock.
- Conexión vía manifiesto tipado en `app/lib/fotorank/contest-assets/`.

Ver: `docs/fotorank/santa-fe-en-foco-asset-ingestion.md`.
