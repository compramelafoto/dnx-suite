# Dashboard patterns (Fotorank)

Patrones reutilizables para vistas de **herramienta** en el panel: cabecera con migas, filtros laterales, estados vacíos y layout de dos columnas.

- Ver reglas en `.cursor/rules/design_rule.mdc` → «Patrones de dashboard».
- Ver documentación extendida en `packages/design-system/docs/FOTORANK_DASHBOARD_PATTERNS.md`.

**Uso rápido**

```tsx
import {
  DashboardPageHeader,
  DashboardBreadcrumb,
  HeaderSecondaryLink,
  TwoColumnToolLayout,
  FilterSidebarCard,
  FilterField,
  DashboardEmptyState,
} from "@/app/components/dashboard-patterns";
```
