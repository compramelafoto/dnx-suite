# Checklist pre-votación pública — Clickatón

**Etapa:** 15B · Usar después del cierre de jurado  
**Fuente:** `jury-and-public-voting-master-rules.md`  
**LEGAL REVIEW REQUIRED** (redes, métricas, transparencia).

---

## Finalistas

- [ ] Jurado cerrado  
- [ ] Desempates de jurado resueltos (si afectaban corte)  
- [ ] **30 finalistas** (3 por cada una de 10 consignas)  
- [ ] Finalistas ≠ ganadores definitivos (copy alineado)  
- [ ] Identidades aún no expuestas al público de forma que rompa reglas de la edición  

## Assets y publicación

- [ ] Assets de finalistas preparados (formato red / carrusel según canal)  
- [ ] Anonimato / crédito según política de la edición  
- [ ] Copy de apertura listo  
- [ ] Canal de publicación definido (no asumir Instagram automático)  

## Ventana y métrica

- [ ] Unidad = **CONSIGNA**  
- [ ] Métrica = **Me Gusta**  
- [ ] `openedAt` / `closesAt` exactos definidos  
- [ ] Duración configurada (default operativo 24 h)  
- [ ] Reloj / timezone de cierre claros  

## Empate y verificación

- [ ] Reglas `PUBLIC_TIEBREAK` comunicadas  
- [ ] Confirmado: **no** se usa score del jurado para desempatar público  
- [ ] Plan si no se puede verificar métrica → `PENDING_PUBLIC_VOTE_VERIFICATION`  
- [ ] No declarar ganador sin verificación  

## Estado plataforma

- [ ] Votación pública OFF hasta GO  
- [ ] RESULTS OFF hasta cierre verificado  
- [ ] Comunicaciones programadas (apertura / cierre / empate / resultado)  
- [ ] Operador de monitoreo de ventana definido  

**GO voto público solo con checklist completa y decisión humana.**
