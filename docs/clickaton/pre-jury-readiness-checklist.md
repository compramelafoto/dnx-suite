# Checklist pre-jurado — Clickatón

**Etapa:** 15B · Usar antes de abrir evaluación  
**Fuente:** `jury-and-public-voting-master-rules.md`

---

## Operación

- [ ] Upload cerrado (o extensión global registrada y vencida)  
- [ ] Reemplazos de participantes resueltos según ventana  
- [ ] Admisión técnica cerrada / cola YELLOW resuelta  
- [ ] Sin `CONFIRMED_REJECTION` pendientes de impacto en elegibilidad  
- [ ] Elegibilidad **congelada** (`minimumCompletedPrompts = 8`)  
- [ ] Roster final de obras ADMISIBLES de participantes ELEGIBLES  
- [ ] Obras de NO ELEGIBLES **excluidas** del jurado (conservadas en archivo)  

## Jurados

- [ ] Invitaciones enviadas  
- [ ] Jurados **ACEPTADOS** suficientes (calculador: déficit = 0 o aceptado por org)  
- [ ] Cobertura: N evaluaciones/foto (default 3) alcanzable  
- [ ] Conflictos conocidos/preexistentes contemplados  
- [ ] Plan de reemplazo definido  

## Scoring / anonimato

- [ ] Rúbrica ACTIVE: 3 criterios, 1–10, pesos iguales  
- [ ] Scoring config del concurso (no hardcode solo Clickatón en core)  
- [ ] Anonimización verificada (sin identidad/EXIF/GPS/ranking al jurado)  
- [ ] Snapshots / assets de jurado listos  

## Ventanas y comunicación

- [ ] `evaluationStartsAt` / `evaluationEndsAt` configurados  
- [ ] Notificaciones de asignación listas (sin enviar hasta GO)  
- [ ] Reglamento + quick guide + FAQ disponibles para jurados  
- [ ] Banner de ranking provisional listo en panel org  

## Gobernanza

- [ ] JURY flag permanece OFF hasta GO explícito  
- [ ] RESULTS OFF  
- [ ] LEGAL REVIEW de Bases v3 (si se publicará copy nuevo)  
- [ ] Operador responsable del día de apertura definido  

**GO jurado solo con checklist completa y decisión humana.**
