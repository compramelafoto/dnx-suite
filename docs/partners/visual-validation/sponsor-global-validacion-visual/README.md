## Notas

- Son **simulaciones** con el **componente real** montado en un harness local.
- Usan un **sponsor ficticio** (`sponsor-ejemplo.svg`); no es una marca real.
- **No corresponden a una campaña activa** ni a producción con flags ON.
- La apariencia final de una campaña podrá utilizar el **logo real** de cada marca.
- Tracking, impresiones y clics permanecen deshabilitados en este pack.
- Un solo CTA: el generado por `PartnerWelcomeInterstitial` (el asset sintético no incluye botón interno).
